# CLASH

A small social app for Berlin: activities on a map, venues, join requests and notifications.

This repository is the **starting point** of the workshop *Mastering Claude Code*
(github.com/nextacademy-io/mastering-claude-code). You build the app yourself, with Claude Code,
from the spec in `docs/SPEC.md`. If you fall behind, check out `NN-start` for the task you are on: it is the state at the start of that task.
